# 追鸟 · Chasing Birds

一个 p5.js 创意动画 Demo：天空中的小鸟自由飞翔，点击/触摸互动。

- 点/触一只小鸟：它变成"被追者"，鸟群追逐它；追到后目标转移，互相追着玩
- 点/触天空：鸟群飞向该点聚集
- 鼠标与手机触摸均支持

▶ Live demo: https://renhugh8698-eng.github.io/starry-flow-field/

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 自包含演示页（p5.js 走 CDN），浏览器直接打开即用 |
| `sketch.js` | 动画源码，可粘贴到 p5.js Web Editor 运行 |

## 运行方式

1. 直接打开 `index.html`，或
2. 打开 https://editor.p5js.org ，新建草图，用 `sketch.js` 内容替换默认代码后点播放。
